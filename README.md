# Sales-Data-Analytics-Dashboard
An interactive Sales Performance Dashboard built using SQL, Excel, and Power BI to analyze sales, profit, regional performance, product performance, and order trends.

## 📌 Project Overview

The Sales Performance Dashboard is a data analytics project designed to analyze sales performance and generate meaningful business insights from transactional sales data.

The project focuses on analyzing key business metrics such as Total Sales, Total Profit, Profit Margin, Average Order Value (AOV), Order Completion Rate, regional performance, category performance, product performance, and monthly sales trends.

The project follows an end-to-end data analytics workflow using Excel, SQL, and Power BI.
