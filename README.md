# Sales Performance Dashboard

## 📌 Project Overview

An interactive Sales Performance Dashboard built to analyze sales, profit, regional performance, product performance, and order trends.

The project follows an end-to-end data analytics workflow using **Excel, SQL, and Power BI**.

## 🎯 Objectives

- Analyze key sales and profit KPIs.
- Identify high-performing regions, categories, and products.
- Analyze monthly sales trends.
- Monitor completed, cancelled, and returned orders.
- Generate actionable business insights.

## 📊 Dataset

The project uses a simulated sales dataset containing **1,500 transactions** from **January–June 2026**.

**Dataset:** [Download / View Dataset](PASTE_YOUR_DATASET_LINK_HERE)

## 🛠️ Tools Used

- Excel – Data validation
- MySQL – Data analysis
- Power BI – Dashboard & visualization

| KPI | Result |
|---|---:|
| Total Sales | ₹5.95 Cr |
| Completed Orders | 1,333 |
| AOV | ₹44,627 |
| Total Profit | ₹1.80 Cr |
| Profit Margin | 30.20% |
| Order Completion Rate | 88.87% |

## 🔍 Dashboard Features

- KPI Cards
- Monthly Sales Trend
- Regional & Category Analysis
- Top Product Analysis
- Order Status Analysis
- Interactive Filters

## 💡 Key Insights

- Central recorded the highest regional sales.
- Electronics was the highest-selling category.
- Laptop was the top-selling product.
- Completed orders accounted for 88.87% of all records.

## ⚠️ Limitations

The dataset is simulated and covers only six months. It does not contain leads or visitor data, so a true marketing conversion rate cannot be calculated.
