# Sales Performance Dashboard

## 📌 Project Overview

An interactive Sales Performance Dashboard built to analyze sales, profit, regional performance, product performance, and order trends.

The project follows an end-to-end data analytics workflow using **Excel, SQL, and Power BI**.

## 🎯 Objectives

- Analyze key sales and profit KPIs.
- Identify high-performing regions, categories, and products.
- Analyze monthly sales trends.
- Monitor completed, cancelled, and returned orders.
- Generate actionable business insights.

## 📊 Dataset

The project uses a simulated sales dataset containing **1,500 transactions** from **January–June 2026**.

**Dataset:** <a href="https://github.com/rajveerchouhan724-gi/Sales-Data-Analytics-Dashboard/blob/main/Sales_analysis_Dataset.xlsx">Dataset</a>

## 🛠️ Tools Used

- Excel – Data validation
- MySQL – Data analysis
- Power BI – Dashboard & visualization

## 🗄️ SQL Analysis

MySQL was used to analyze the sales dataset and calculate key business metrics and performance insights.

The SQL file includes:
- Data overview and record checks
- Sales, orders, AOV, profit and profit margin
- Regional and category performance
- Monthly sales analysis
- Order status and completion rate
- Product performance analysis

📄 **SQL File:** <a href="https://github.com/rajveerchouhan724-gi/Sales-Data-Analytics-Dashboard/blob/main/Sales%20SQL%20file.sql">SQL</a>

## 💡 Key Insights

- Central recorded the highest regional sales.
- Electronics was the highest-selling category.
- Laptop was the top-selling product.
- Completed orders accounted for 88.87% of all records.

## ⚠️ Limitations

The dataset is simulated and covers only six months. It does not contain leads or visitor data, so a true marketing conversion rate cannot be calculated.

## 🚀 Future Improvements

- Target vs Actual analysis

## 📌 Conclusion

This project demonstrates an end-to-end data analytics workflow by transforming raw sales data into meaningful business insights through data validation, SQL analysis, and interactive Power BI visualization. The dashboard provides a clear view of sales, profitability, regional and product performance, helping stakeholders monitor key KPIs, identify trends, and support data-driven decision-making.
